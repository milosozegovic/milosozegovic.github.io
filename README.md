# milosozegovic.com

Personal site and portfolio. Hand-written HTML, CSS and SVG — no framework, no
build step, no dependencies, no third-party requests.

## Why it's built this way

The site argues that I care about performance and about not reaching for
machinery a problem doesn't need. It would be odd to make that argument through
a 400 KB JavaScript bundle. So:

- **No build step.** The files in this repository are the files served.
- **No dependencies.** No CDN, no analytics, no web fonts. Every byte is local.
- **Charts are hand-drawn SVG.** The diagrams in the case studies are written
  by hand rather than generated by a library.
- **Works without JavaScript.** There isn't any.

Total page weight is around 120 KB including images.

## Structure

```
index.html                          home
work/clickhouse.html                case study — 1.5B-row MySQL → ClickHouse migration
work/engineering-analytics.html     case study — delivery analytics over Jira + GitHub
styles.css                          one stylesheet
img/                                portrait and avatars (WebP with JPEG fallback)
404.html                            not-found page
CNAME                               custom domain for GitHub Pages
.nojekyll                           skip Jekyll processing
```

## Local development

No tooling required:

```sh
open index.html
```

Or serve it, if you'd rather test with absolute paths:

```sh
python3 -m http.server 8000
```

## Deployment

Pushing to the default branch deploys to GitHub Pages, which serves
`milosozegovic.com`.

## Conventions

- Semantic HTML, one `<h1>` per page, correct heading order
- Keyboard navigable with visible focus states; skip link on every page
- `prefers-reduced-motion` respected
- Responsive from 320px
- Images sized to their display dimensions, not shipped oversized
